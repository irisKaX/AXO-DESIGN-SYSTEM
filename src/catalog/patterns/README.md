# Patterns

`PatternDemos.tsx` skládá devět funkčních lokálních sestav z veřejných AXO komponent.
`registry.ts` drží jejich navigační metadata a `PatternsPage.tsx` poskytuje přehled/detail.
Stejný registr používá Playground pro předpřipravené sestavy.

Přihlášení, uložení profilu a opakování operace jsou demonstrační; nemají backend.
Data Table, potvrzení a validace znovu používají stejné příklady a komponenty.
